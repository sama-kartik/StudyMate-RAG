      About StudyMate

      AI-Powered Learning Management System Chatbot using Retrieval-Augmented Generation (RAG)

      How it works

      1. Your PDF's text is extracted in the browser and split into overlapping chunks.
      2. Each chunk is turned into a 768-dimensional embedding with Google Gemini.
      3. Chunks and embeddings are stored in your browser (IndexedDB), forming the vector store.
      4. A question is embedded the same way; the most similar chunks are found by cosine similarity.
      5. Gemini writes an answer using only those passages, citing each one with its page number.
